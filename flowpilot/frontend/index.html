Frequently asked questions

Can't find what you're looking for? Reach out and we'll help directly.

Do I need to connect my own AI provider?

No — FlowPilot works out of the box. If you'd like to use your own model provider, that can be connected in workspace settings.

Can I import existing clients and projects?

Yes, via CSV import during setup, or by connecting an existing tool through our migration assistant.

What happens if an automation fails?

Every run is logged. Failed runs notify the workspace owner and can be retried or edited before re-running.

Is there a limit on team members?

Starter supports up to 3 members. Growth and Scale plans support larger teams — see pricing above.
